# catalog-web-frameworks

Web framework implementations measured by BenchCommons.

This catalog continues the archived TechEmpower Framework Benchmarks; see `.github#2` and ADR 0004 in [.product](https://github.com/BenchCommons/.product). Implementations follow the catalog contract owned by benchmark-tool (benchmark-tool#29).

Status: starting. The first spec is being defined in issue #1. Specs live in `docs/specs/<NNN>-<feature>/`.
